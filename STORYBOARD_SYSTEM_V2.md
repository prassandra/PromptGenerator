# Driacom Storyboard System v2

This package adds a unified multi-engine storyboard specification.

## Engine-specific modals
- Prompt AI Animasi: visual + motion + camera + transitions
- Prompt AI Storytelling: story arc + character + emotion + dialogue + continuity
- Prompt AI Affiliate: hook + product demonstration + proof + benefit + CTA

## Common workflow
Input → Generate Storyboard → Review/Edit → Generate Scene References → Generate Video Prompts

## Continuity
All engines share character, product, environment, and camera continuity locks where applicable.

The machine-readable schema is available at:
`public/driacom-storyboard-system-v2.json`
