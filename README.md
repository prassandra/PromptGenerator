## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Admin login (temporary test auth)

Admin login uses a username instead of email. Keep the password in `.env.local`; never commit it.

```env
DRIACOM_ADMIN_USERNAME=prassandrasandria
DRIACOM_ADMIN_PASSWORD=PUT_YOUR_ADMIN_PASSWORD_HERE
```

Member login/register remains email-based and will be connected to Supabase Auth in the next auth/database step. The temporary admin session is only for local testing and must be replaced by Supabase/server-side auth before production.

## AdSense web inventory
The web build includes responsive top/bottom placements plus desktop side-banner placements using the configured AdSense side slot. AdSense controls whether an individual request is filled; the app cannot guarantee an ad will be returned for every request.
